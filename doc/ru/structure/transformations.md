# Трансформации

## Общие сведения

Механизм трансоформаций основан на матрицах четырехмерных матрицах трансформации (или матрицах преобразований). Матрицы трансформаций являются математическим инструментом, позволяющим описывать геометрические преобразования объекта в пространстве с помощью операции умножения координат этого объекта на соответствующую матрицу.

Матрицы трансформации строятся на основе однородных координат (гомогенных координат). Однородные координаты — это представление точек пространства в проективной геометрии, при котором к обычным координатам добавляется дополнительная компонента. Такое представление позволяет выразить операцию переноса через умножение на матрицу, что невозможно в обычных (аффинных) координатах, где перенос является нелинейной операцией. Благодаря этому все аффинные преобразования (перенос, поворот, масштабирование) сводятся к единой операции умножения, а композиция произвольного числа преобразований выражается перемножением соответствующих матриц.

Поддерживаются следующие операции трансформации:

+ Перенос (Сдвиг)

+ Поворот

+ Масштабирование

## Реализация

Для представления трансформаций двухмерных координат используются матрицы размера 4х4. Матрицы данной размерности являются стандартом в OpenGL и позволяет сделать координаты однородными. Для однородности координат достаточно лишь расширить матрицу 2х2 до 3х3.  Двумерная точка (x, y) представляется как четырехмерный однородный вектор (x, y, 0, 1). Дополнительная компонента w позволяет выразить операцию переноса через матричное умножение, что в двумерных координатах невозможно — перенос там является нелинейной операцией. Двумерные преобразования реализуются поверх трехмерных примитивов: координата z фиксируется равной 0, а поворот выполняется вокруг оси Z.
